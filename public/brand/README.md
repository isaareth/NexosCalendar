# Assets de marca

- `logo-nexos.jpg` — logo oficial de NEXOS (wordmark azul marino + acento turquesa,
  "Periódico Estudiantil"). Header/masthead y color de la categoría `General`.
- `logo-nexos-creativo.jpg` — variante artística/hecha a mano del logo (fondo negro, tonos
  tierra: verde salvia, ladrillo, arena). Asset **decorativo**, no funcional — informa la
  paleta secundaria "editorial cálida" (fondos tipo papel, grises cálidos), no el color de
  ninguna categoría.
- `deportes.png` — escudo de NEXOS para deportes (morado/lavanda). Un solo escudo
  compartido por **Fútbol, Vóley y Básquet** — las tres subcategorías deportivas usan el
  mismo color de marca; se distinguen entre sí por el texto de la categoría, no por el
  color (FR-019).

Colores extraídos y su justificación en
[../../specs/001-nexos-agenda/research.md §8](../../specs/001-nexos-agenda/research.md#8-paleta-de-colores-por-categoría).
No quedan assets pendientes para esta feature.
