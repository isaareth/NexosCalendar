# Assets de marca

## Estado

- [x] `logo-nexos.jpg` — logo oficial de NEXOS (wordmark azul marino + acento turquesa,
      "Periódico Estudiantil"). Usado como header/masthead y colores de la categoría
      `General`.
- [x] `logo-nexos-creativo.jpg` — variante artística/hecha a mano del logo (fondo negro,
      tonos tierra: verde salvia, ladrillo, arena). Es un asset **decorativo**, no
      funcional — informa la paleta secundaria "editorial cálida" (fondos, ilustraciones,
      estados vacíos), no el color de ninguna categoría.
- [x] `sports/futbol.png` — escudo real de "NEXOS Fútbol Club" (morado/lavanda). Usado para
      el color de la categoría `Deportes - Fútbol`.
- [ ] `sports/voley.png` — **pendiente**. Sin este archivo, `Deportes - Vóley` usa un color
      neutro temporal en `lib/theme.ts`.
- [ ] `sports/basquet.png` — **pendiente**. Sin este archivo, `Deportes - Básquet` usa un
      color neutro temporal en `lib/theme.ts`.

Los colores extraídos de cada imagen y su justificación están documentados en
[../../specs/001-nexos-agenda/research.md §8](../../specs/001-nexos-agenda/research.md#8-paleta-de-colores-por-categoría).

Formato preferido para los que falten: PNG con fondo transparente, resolución razonable
(≥512px de lado mayor), igual que `sports/futbol.png`.
